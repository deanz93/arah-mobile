# arah-mobile

React Native 0.74 mobile app for the [Arah](https://github.com/deanz93/arah) navigation platform.
MapLibre GL maps, Valhalla routing, Nominatim geocoding, community hazard reports,
Firebase Auth + Firestore, TTS turn-by-turn guidance in Bahasa Malaysia.

## Quick start
```bash
cp .env.example .env
npm install
# Android
npx react-native run-android
# iOS
cd ios && pod install && cd ..
npx react-native run-ios
```
